## 推荐

条件性推荐 **B：以 Open Notebook 为主体，隔离组合科研证据与解析模块**；须在阶段二平台验证后重新评估，尚未定案。理由是已有 Web、资料管理、全文/向量检索、问答基础，同时能够把团队开发集中在十字段矩阵、引用支持判定、章节报告与 AgentArts 真实自主工作流上。

若最终采用 B，可评估保留 Open Notebook 的 Next.js/FastAPI/SurrealDB 结构；不得先于平台验证锁定业务架构。PaperQA 作为可替换的独立证据服务，Docling 按复杂 PDF 样本效果决定是否启用。不是直接把多个完整 Agent 串联。若团队工期充裕且倾向彻底控制数据结构，则 C 更可控。

最终方案受比赛期限、团队能力、华为云账号可用能力和比赛对 SDK 模式认可情况影响。以下人周是工程估算，不是报价或交付承诺；按 1 名熟悉 Python/TypeScript 工程师的有效工作量计算，不含账号等待、论文/专利工作、长周期评测及正式云部署；并行投入不能简单线性缩短时间。

## 三种方案

| 项目 | A：完整项目二开 | B：主项目 + 独立模块（推荐） | C：轻量组件 + 自研业务 |
|---|---|---|---|
| 主体 | Open Notebook | Open Notebook + 隔离 PaperQA/可选 Docling | 自研 Web/API + PDF 组件 + 模型适配 |
| 技术架构建议 | 沿用 Next.js、FastAPI、SurrealDB、worker | 同 A，独立证据服务经受控适配调用 | React/Next.js 或 Vue 二选一；FastAPI；SQLite 起步或 PostgreSQL，待确认 |
| 已有功能覆盖 | 资料库、分类基础、搜索、QA、笔记 | A + 科研证据收集/页范围工具基础 | 无现成完整产品；解析和模型客户端可复用 |
| 必须自研 | 学术字段、十字段矩阵、引用判定、报告章节/Word、学术 API、AgentArts | 同 A，外加统一页锚点、跨服务 ID、证据来源映射 | 全部业务、文件管理、检索、阅读器、任务状态；组件不包办业务 |
| 自主开发空间 | 中 | 高，聚焦科研证据链 | 高，产品控制充分 |
| 工作量估计 | 10–15 人周 | 12–18 人周 | 16–24 人周 |
| 部署难度 | 中；两服务及持久卷 | 中偏高；多一个隔离服务，复杂解析按需启动 | 初始低至中；后续 worker/检索增加服务 |
| 本机资源建议 | 云模型、低并发、小文献库优先验证 | 证据服务与 OCR 避免同时高并发 | 可精简；本地大模型仍受内存约束 |
| AgentArts 集成难度 | 中；已有 API 需包装业务语义 | 中；模块边界清楚，但状态与映射要测试 | 中；可以直接围绕工具契约开发，但代码量更大 |
| 扩展性 | 受现有 schema 与上游升级约束 | 较好，可替换解析和检索模块 | 最高，但全部维护责任由团队承担 |
| 许可证风险 | MIT 主体；依赖、MCP、权重另查 | MIT + Apache-2.0；可选解析器另查 | 可选择宽松组件；自研不意味着无第三方风险 |
| 主要失败风险 | 基础体验可用但证据链不足 | 多组件重复检索/索引、两套规划器冲突 | 前期大量时间耗在通用产品基础 |

A 的替代完整项目可考虑 RAGFlow，但当前 Go/原生依赖及 16 GB 推荐起始资源不适合本机优先；GPT Researcher 若作为主体，文献库持久化、分类和科研证据的补齐量偏大。

## AgentArts 官方核查

### 已读取的官方材料

华为云组织维护的 [agentarts-sdk-python](https://github.com/huaweicloud/agentarts-sdk-python)，Apache-2.0，pyproject 版本 0.1.11；本次元数据最近 push 为 2026-11-13。

已读：
- [Runtime 指南](https://github.com/huaweicloud/agentarts-sdk-python/blob/main/docs/cn/sdk_user_guide/runtime_user_guide.md)
- [Runtime 源码](https://github.com/huaweicloud/agentarts-sdk-python/blob/main/src/agentarts/sdk/runtime/app.py)
- [Gateway 指南](https://github.com/huaweicloud/agentarts-sdk-python/blob/main/docs/cn/sdk_user_guide/gateway_user_guide.md)
- [Invoke 指南](https://github.com/huaweicloud/agentarts-sdk-python/blob/main/docs/cn/toolkit_user_guide/invoke.md)
- README、LICENSE、pyproject.toml。

文档与源码共同确认：
1. AgentArtsRuntimeApp 为 ASGI 包装，提供 POST /invocations、GET /ping 和 WebSocket /ws；支持流式生成器和请求/会话上下文。
2. Runtime 代码确实注册这些路由；这是 SDK 包装后 Agent 服务的路由，**不是已验证的华为云公共网关完整 URL**。
3. 指南提供部署与云端调用方式、AK/SK 签名和 Bearer 认证说明；真实云端 endpoint、区域、权限、出站网络需从用户实际控制台核实。
4. Gateway SDK 指南包含 MCP gateway、目标配置和 IAM/api_key/custom_jwt 授权描述；不能据此假定任意本地 stdio 工具可被云端直接访问。
5. invoke 的默认 timeout=900 是客户端等待参数，不是平台任务时限或持久化保证。
6. async_task 是运行中任务跟踪；不能推断重启后可恢复，也不能替代持久化队列/检查点。

访问 support.huaweicloud.com 与产品页得到安全验证/脚本页；docs.huaweicloud.com/agentarts 出现 TLS EOF。已保留响应，不把 HTTP 200 误记为正文阅读成功。官方 GitHub SDK 是本次实际可读的官方技术依据。未绕过验证码，未登录控制台。

### 当前集成优先级（2026-11-17 修订，未执行）

优先在 AgentArts 平台创建、编排并部署核心智能体，Web 通过官方 API 调用；本地检索、PDF、分析与核验工具仅按实际支持的 HTTP/MCP 接入。具体节点、协议和发布接口未核实，不能写为已支持。

原“SDK Runtime 优先核验”建议撤销。SDK 仅保留为平台实际支持的调用或构建/部署辅助候选；本机 SDK 服务运行、模板代码或路由存在均不满足平台工作流验收，也不得用完全独立本地 Agent 替代。

阶段二必须取得真实工作流创建/编排、平台部署、官方 API 调用与外部业务工具调用的证据，并同步核实模型资源、接口/网络/部署限制与费用。若无法验证，暂停受影响路线并汇报；不进入核心业务大规模开发。详见根目录开发计划。

### 应承担的实质工作

建议由 AgentArts 部署/编排的核心 Agent 根据研究任务决定检索词、资料范围、证据需求与调用顺序，调用文献检索/解析/分析工具，检查矩阵缺项、回查证据，对失败步骤调整查询或缩小范围，最后验证报告引用完整性后提交结果。Web 与本地后端承担文件、编辑、任务状态及可靠执行记录。

需要展示完整 trace：任务 → 计划 → 工具入参与结果 → 证据检查 → 有界调整 → 报告。仅部署一个透传聊天入口，或让本地 Agent 完成所有研究再在 AgentArts 包一层，不满足目标。

长任务建议：业务层持久化任务与步骤，采用 job_id、幂等键、步骤检查点、预算/重试上限；Web 用进度事件或轮询。是否可由云端持久化恢复须实测。云端访问本机 127.0.0.1 不可行；建议后续同 VPC 服务或经认证的 HTTPS 工具网关。本次计划修订不开放端口、建网关或部署；阶段二验证资源须在用户确认范围与预算内处理。
