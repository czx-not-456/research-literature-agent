# 文献对比矩阵

## 使用方法

在课题文献库打开「对比矩阵」，选择至多六篇同课题文献并应用筛选。首次打开显示最近导入的至多六篇已保存文献。「从 PDF 提取候选」扫描所选文献的本地页文本，将匹配的原文绑定到十个字段的候选位置。找不到规则线索的字段显示「待补充」。

十个字段为研究问题、研究背景、核心方法、创新点、数据集、实验设置、评价指标、主要实验结果、研究局限、未来研究方向。可按字段筛选，或只显示具备原文的字段与单元格。

每格可点击「编辑」修订内容。带页码的修订必须附上一段能在同一 PDF 页定位的连续原文。页码为文件中的实际顺序。证据匹配只确认引文出现的位置；人工结论是否由该引文支持仍需阅读判断。用户可手动补充或清空单元格，后续提取会保留已编辑字段。删除文献时对应矩阵字段一起清除。

「导出 CSV」导出当前筛选结果，每行是一篇论文的一个字段，记录内容、来源标签、PDF 页码与引文。文件以带 BOM 的 UTF-8 保存，便于在 Excel 中打开。看起来像电子表格公式的文本会被转成普通文本。

## 实现和边界

本轮使用 SQLite 新增按文献与字段索引的表，沿用既有 PDF 页文本及其主键。自动提取是确定性的中英文规则匹配，启动时无需新的依赖或模型额度。内容是候选摘录，需要用户审核。隐含结论、措辞超出规则范围、扫描件或复杂版式都可能导致空字段或相关性较弱。

AgentArts 仍对应项目的云端智能体路线。问答已提供官方接口客户端，平台真实调用和自主工具编排尚待验证，本轮环境没有 IAM 凭据。矩阵原文候选流程已在本地独立验证。[问答验收和平台边界](literature-qa.md)

## 验收

- 21 项自动化测试通过。矩阵覆盖十字段填充、原文跳转、手动字段保留、证据错误拒绝、跨课题隔离、文献删除联动和 CSV 导出。
- 两篇公开论文各生成 8 个候选，共 16 个。逐条检查摘录出现在对应 PDF 页文本，CSV 共 16 个数据行。每篇选一处确认 PDF 预览，Chrome 在 1280 和 412 像素窗口加载十行矩阵。候选数量记录的是规则命中数，字段语义准确率尚无人工参考集评估。[Attention Is All You Need](https://arxiv.org/pdf/1706.03762) [Retrieval-Augmented Generation for Knowledge-Intensive NLP Tasks](https://arxiv.org/pdf/2005.11401)
