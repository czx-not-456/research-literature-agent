# 旧文献库批量更新

## 使用方法

打开课题文献库，点击「批量更新文献」，勾选 1 至 6 篇本地 PDF 并生成预览。可展开矩阵字段对照原候选与新候选，点击页码核对原文。核对后点击「应用预览中的更新」。应用结果会显示更新文献、补齐元数据和调整矩阵候选的数量。[应用入口](../../README.md)

## 更新范围

- 重新从原件读取前两页来补齐作者、发表年份、DOI、关键词和摘要。已有值和明确记录为手工清空的字段受到保护。证据不足的字段继续留空。
- 矩阵候选用已保存的逐页原文生成，新增有证据的候选，替换较早的自动摘录。仅在所有页面均有完整可用文本且新规则找不到相应候选时，才建议移除旧自动候选。手工单元格受到保护。
- 报告保存时的书目与引用快照继续可读。新候选的原文位置使用原件的物理页码。
- 预览通过课题与所选文献范围签名，15 分钟内有效。应用时重算变化，并在同一 SQLite 写入事务中核对手工修改与引文。发现冲突时整批回滚，页面提示重新预览。原件解析失败的文献在预览中标明。

## 验收记录

52 项自动化测试通过。新增测试覆盖预览只读、候选新增及替换及移除、空字段与手工项保护、快照保留、重复提交、跨课题令牌和确认期间发生编辑时的整批回滚。

使用 BERT 与中文机器阅读理解综述的公开原件，按历史版本的抽取和矩阵规则写入隔离 SQLite。通过现有 Web 表单预览并应用后，分别补齐 2019 年和 2022 年，中文作者列表正确补齐。数据集候选从物理第 3、2 页分别更新至第 5、6 页。BERT 的 DOI 继续留空。验证在隔离库中完成，用户库的实际应用需要在对应课题确认预览。[公开样本与人工标注](../system-testing/quality-results.md)
