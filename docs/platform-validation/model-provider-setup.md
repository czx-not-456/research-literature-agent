## 如何选协议

- 已开通华为云MaaS：以该模型实际调用示例为准。页面有“MaaS标准API V1”不表示MaaS所有版本都应选这一项。
- 官方参考资料另列MaaS标准V2和OpenAI兼容路径，故不能把V2请求格式填进V1选项；若使用MaaS的OpenAI兼容方式，应核对平台标准OpenAI选项和Base_url的路径拼接约定。
- 已有其他模型API：只有该服务实际提供对应协议且可从AgentArts运行网络访问，才作候选，不把协议名称视作厂商所有功能均兼容。
- 没有模型API：先核查华为云MaaS可用模型、额度和按量价格，提出具体低成本候选后再选定；无需为此采购本地GPU、云服务器或独立Agent系统。
