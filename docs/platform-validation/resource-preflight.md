## 此前套餐核查事项（授权后最新状态见文末）

先点击模型页顶部“免费领取体验版”，打开详情/申请说明页，提供该页截图；先不点击最终领取、购买或支付，不接受尚未读清的自动续费条款。
需要核实：
1. 当前账号/区域能否领取，是否须公测审核，是否已领取或已用尽。
2. 有效期、免费额度和数量、包含的Managed Agents/环境/网关等能力。
3. 是否包含模型推理，还是只包含平台权益；支持的模型来源与可用型号。
4. 超额或到期后停止还是计费，是否自动续费，是否要求余额或欠费处理。
5. 后续代金券适用范围，不能按“有比赛代金券”推定此套餐和模型费用都可抵扣。

若该入口直接显示已领取/待审核/领取失败，提供实际状态即可，不重复操作。若点击即直接领取并未经过详情确认，则记录真实结果，本轮不编造该行为一定无副作用。

得到明确条款后，再据用户既有低成本授权判断可执行的免费验证范围；如涉及付费，先给出具体金额/资源/期限与清理方案供确认。阶段二仍进行中，不改成独立本地Agent，不进入阶段三。
