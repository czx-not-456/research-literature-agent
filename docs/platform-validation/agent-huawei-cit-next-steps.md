## 现在优先做：查看工具接入方式

1. 在该详情页点击右上角“编辑”。
2. 找到之前已出现的“工具与Skill”区域，展开“内置工具”下拉；查看“选择Skill”窗口中可用类型、来源和配置字段。
3. 提供上述工具/Skill可选项与接入配置截图。这里只查看，不猜测有HTTP/MCP选项，不新购网关或托管资源。
4. 若编辑页只有内置工具/资产Skill而没有外部接口配置，再根据实际入口查看网关或资产的接入方式；不要把SDK中的MCP能力直接当作本页已可用功能。

本轮目标只接入一个真实文献检索工具：输入短关键词与结果数量（1–2条），经已核实的Crossref查询返回题名、DOI、来源链接及存在的元数据；缺字段标未核实，不生成全文页码。
现有本地探测脚本是可复用业务逻辑，不是已部署给AgentArts的工具。具体HTTP/MCP契约、认证、托管和费用确定后，只开发阶段二必要薄适配，不启动正式业务系统。

可准备的短提示词（尚未提交）：
> 你是科研文献调研验证助手。需要检索时调用已配置的真实文献工具。只依据工具返回整理题名、DOI和来源链接；缺失信息标为未核实。工具不可用或失败时明确说明，不用模型记忆冒充检索结果。没有全文时不提供页码或原文片段。

提示词不注册工具，也不证明模型会正确调用；工具配置和执行轨迹才是验收证据。

## 同步获取：官方调用信息

- 用“访问域名”旁的复制按钮获取完整值，提供非敏感域名文本即可，不要根据截图截断值拼接。
- 若版本、详情或相关运行时页面提供API说明/调用示例，提供脱敏示例：保留HTTP方法、完整路径、请求体字段，去掉Key/Token。
- 出站DeepSeek API Key用于Agent调用模型；外部客户端调用AgentArts时的入站认证需按平台实际方式配置，不能把两者当成同一个凭据。
- 域名和UUID本身不足以确定路径、鉴权、同步/流式格式。没有官方示例则先查适用平台文档，不构造假API。

## 获得工具契约后的验证顺序

1. 核对短提示词、模型参数和上下文；记录新Agent的实际配置。
2. 绑定一个真实检索工具，用一个短研究主题执行一次平台任务，保留真实工具参数、结果及最终回答；无工具则明确失败，不能用通用聊天结果替代。
3. 对同一已确认版本做一次外部官方API请求，关联平台/工具日志。
4. 验证非法参数或无结果等受控失败，不冲击配额，不批量调用。
5. 记录发布/版本、用量、费用或待结算状态，完成阶段二总结后等待下一阶段确认。
