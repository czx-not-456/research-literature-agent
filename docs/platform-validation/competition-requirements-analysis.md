# 初赛赛题要求核对

日期：2026-11-17。依据：[用户提供的官方赛题文档](../../赛题要求.md)。原文件只读保留，内容校验值见 evidence/competition-source.json。本次未获得大赛官网原始附件，文件的官方来源属性由用户提供；不虚构主办方通知或模板。

## 明确要求与阶段差异

| 条目 | 赛题原文含义 | 本项目行动 |
|---|---|---|
| 平台要求 | 基于AgentArts完成构建、编排与部署 | 阶段二验证真实平台链路；不以独立本地Agent代替 |
| 展示方式 | 通过可视化Demo页面展示核心功能与交互 | 后续实现真实交互，不能静态页面冒充；本阶段最小客户端不算完整Demo |
| 初赛必交 | 作品信息收集表（Word） | 取得官方模板、截止日期与团队信息后，在获准阶段制作；本次不代填 |
| 初赛材料内容 | 简介与创意、团队、Agent方案（场景/编排/架构/模型与资产）、行业问题/落地场景、Demo视频 | 必须保留平台构建与运行证据；未完成内容不得包装成演示完成 |
| 初赛视频 | 基于AgentArts构建与运行的完整流程 | 录制计划覆盖平台配置、运行、工具调用及真实结果，不只拍最终答案 |
| 初赛链接 | 明确“不要求提供Demo链接” | 不为初赛提前购买公网Web部署资源；仍须做真实平台部署与运行验证 |
| 初赛评分 | 创新性60%，应用价值40% | 清楚论证科研痛点、现有工具差异与合理Agent架构，不以功能数量替代 |
| 中国总决赛 | 需要在线可交互Demo地址、PPT、设计/知识库/模型与资产说明、适用Skill/MCP说明及分享帖截图 | 保留后续正式部署计划，不提前声称达到决赛要求 |
| 分享要求 | 入围中国/全球总决赛作品需分享帖 | 当前初赛不据此自动公开技术；后续与IP评估协调 |
| 云资源 | 代金券/限定云服务支持，发放额度、范围、有效期以最终通知为准 | “后续可用”不等于已到账/全服务可抵扣；账单与资格实际核查 |

初赛“不要求链接”不等于不需要Demo视频、平台构建运行或真实业务。也不能据此自动缩减用户原定A–E产品目标；可将演示、资料准备顺序优先，但范围调整需确认。

## 当前验证范围

继续修订计划的阶段二：真实平台创建/编排 → 发布/部署 → 官方API调用 → 外部真实业务工具 → 平台处理结果。平台模型、知识库、多Agent、效果评估等环节的具体使用须按真实需求和能力核验；题面提到这些环节不等于每项都为本项目必选项，也不证明账号支持全部能力。

本阶段只做小型验证及必要薄适配，不制作初赛Word/PPT/视频，不进入阶段三详细设计或阶段四核心开发。
