# 系统测试与质量优化记录

本轮经用户确认，先验证可独立运行的文献库功能。AgentArts 自主工具编排继续暂缓。验收结果覆盖本轮样本和测试条件。[AgentArts 验收状态](../platform-validation/managed-research-workflow.md)

## 环境与复现

Windows 11 22631、Python 3.12.4、项目现有 Flask、pypdf、PDFium、Pillow 和 SQLite，Word 16.0 用于实机打开和渲染。复现脚本通过 Flask 测试客户端执行真实视图、CSRF 表单和文件下载，每次创建独立的临时 SQLite 数据库。它从出版方下载两份样本，并按 SHA-256 校验。预览和导出留在指定临时目录，项目仓库只保存复现代码与记录。[复现脚本](check_library.py)

```powershell
.\.venv-library\Scripts\python.exe -B -X utf8 -m unittest discover -q
$qaDir = Join-Path ([IO.Path]::GetTempPath()) ('research-library-qa-' + [guid]::NewGuid().ToString('N'))
.\.venv-library\Scripts\python.exe -B -X utf8 docs/system-testing/check_library.py $qaDir
```

小样本中的页面文本覆盖、字段匹配和证据定位分别按上述分母计算。矩阵自动候选在此轮验证了证据关联和编辑导出。抽查时发现摘要被列为数据集候选，分类准确性仍需扩展人工标注样本后测量。

## 已修复问题

- BERT 样本中，反复出现术语的第 8 和第 13 页挤掉含完整查询短语的第 2 页。检索增加完整短语优先级，允许 PDF 引号、换行和连接符造成的常见词间断点。实测第 2 页回到证据列表，并新增回归用例。
- Word 把每行抽取文本当作独立段落，导致同一份双语报告占 12 页。单次换行改为 Word 段内换行，保留空行分段与引文内容。修复后同一报告为 10 页，参考文献同页可见。

独立测试已交付。元数据漏项、扫描件 OCR、矩阵语义评价、arXiv 成功复验及 AgentArts 云端验收保留在待办。
