# 八篇论文矩阵全字段评测

本轮在旧文献库交付获确认后，执行系统测试中剩余的矩阵扩大抽样与 arXiv 实网复验。矩阵入口通过 Flask 的真实导入、生成和页级存储操作测试。运行环境为 Windows 11、Python 3.12.4、项目既有依赖和隔离 SQLite。[脚本](check_quality.py) · [样本与标注](matrix-benchmark.json)

## 样本与判定方法

沿用 BERT、ChineseBERT、中文机器阅读理解综述及中文语义角色标注四篇，新增 COMET、CLiMP、中文知识库问答及中文实体关系抽取四篇。每份 PDF 经 SHA-256 校验。八篇共设 66 个明确的页级标注，覆盖矩阵全部十个字段类型。其余 14 个文献字段组合未评分。[COMET](https://aclanthology.org/2020.emnlp-main.213/) · [CLiMP](https://aclanthology.org/2021.eacl-main.242/) · [中文知识库问答](https://html.rhhz.net/tis/html/201707039.htm) · [中文实体关系抽取](https://html.rhhz.net/tis/html/202204047.htm)

评分要求候选页码和所有人工参考锚点匹配。未输出候选记作「缺失」，输出其他原文记作「不同候选」。不同候选可能同样能支持字段，需要补充人工标注后再判断。例如 CLiMP 的数据生成段落交代了语料创建方式，当前参考选择的是数据集规模与对照类别。引文定位单独按原候选能否逐字落在保存的物理页算。规则前后均在同一语料复测，结果用于定位问题与确认修复。

## 修复与失败案例

- 参考文献的标题可能以中英文冒号结束。矩阵截断同时识别这种格式，避免把参考条目的标题当成本篇证据。新增回归用例验证这条边界。
- 原规则将 COMET 的「便利未来研究」脚注选为未来方向，遗漏结论中的模型压缩计划。改为匹配明确的将来行动，并识别中文 PDF 中跨行的「未来的工作」。复测四个已标注的未来工作均命中。
- 实测修复「试验环境」、跨行指标声明和数据集来源的漏选。中文实体关系抽取论文的数据集、试验环境、指标与未来工作取得预期页码。
- 仍有实质缺口。ChineseBERT 研究局限可能误取作者为解决旧问题描述的词语，当前五条局限标注均未命中。中文语义角色标注的结果候选可能引用前人实验，未命中本文量化结果。除非完成字段人工核对，矩阵候选只能作为原文线索。

## arXiv 实网复验

在隔离课题的「在线检索」中选择 arXiv，检索词为 BERT Pre-training of Deep Bidirectional Transformers。网页真实返回 3 条结果，约 0.99 秒。提交导入后返回 HTTP 302，库中新增 1 条，来源为 arXiv，保存了真实原始链接和版本。该次检索成功，之前的流量限制仍应按正常错误路径处理。[导入的公开记录](https://arxiv.org/abs/1810.04805v2)
